# 🪟 DSA Window — DSA Progress Tracker

A comprehensive, full-stack platform designed to help developers systematically master the curated **DSA 450 problem set**. It transforms a static list into a dynamic, personalized learning environment.

---

## 🌟 Key Features

*   **📈 Personalized Progress Tracking:** Built a full-stack tracking platform that persists user data.
*   **🔐 User Authentication:** Secure login and registration to maintain individual progress and bookmarks.
*   **🔖 Study Tools:** Added per-question bookmarking, completion toggles, and private notes for documenting logic.
*   **🔍 Smart Filtering:** Designed advanced search and filtering based on problem status, topics, and keywords.
*   **🛡️ Dynamic Admin Panel:** Developed a secure dashboard to manage topics and questions dynamically.
*   **📱 Responsive UI:** A clean, frontend-focused interface built for a seamless user experience.
